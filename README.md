# Betchi Pet Shop

Betchi Pet Shop es un proyecto de una página web para un pet shop. La idea es mostrar los productos disponibles y brindar información útil para las personas que tienen mascotas.

El sitio cuenta con distintas secciones para poder navegar de forma simple y encontrar la información necesaria.

## Tecnologías utilizadas

- HTML
- CSS
- Git
- GitHub

## Secciones

- Inicio
- Productos
- Galería
- Preguntas frecuentes
- Contacto

## Cómo empezar

Para ver el proyecto de forma local:

1. Clonar o descargar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo `index.html` en el navegador.
