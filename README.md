# Betchi Pet Shop

Betchi Pet Shop es un proyecto de una página web para un pet shop. La idea es mostrar los productos disponibles y brindar información útil para las personas que tienen mascotas.

El sitio cuenta con distintas secciones para poder navegar de forma simple y encontrar la información necesaria.

## Tecnologías utilizadas

- HTML
- CSS
- Git
- GitHub

## Secciones

- Inicio
- Productos
- Galería
- Preguntas frecuentes
- Contacto

## Cómo empezar

Para ver el proyecto de forma local:

1. Clonar o descargar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo `index.html` en el navegador.

También se puede visualizar desde GitHub Pages en el enlace que se encuentra al comienzo del README.

## Colaboración

Para realizar las mejoras del proyecto se trabajó utilizando Feature Branching, creando ramas independientes sin modificar directamente la rama `main`.

También se utilizaron Issues para registrar las tareas a realizar y Pull Requests para revisar los cambios antes de integrarlos a la rama principal.

En la última mejora se trabajó sobre la rama `informacion-contacto`, donde se agregó información de WhatsApp, email, horarios, ubicación y mapa en la página de contacto.
